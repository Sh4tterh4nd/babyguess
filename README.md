# BabyGuess

BabyGuess is a planned self-hosted guessing game for friends of expectant parents. Participants privately
predict the baby's name and, when enabled, sex, birth date, and birth weight. After the baby arrives, the
administrator publishes a scored leaderboard.

The application will be an independent Spring Boot and Thymeleaf project with its own Gradle build,
application port, persistence, and Jib-built container image.

Development has not started yet. The agreed product behavior and initial acceptance criteria are documented
in [REQUIREMENTS.md](REQUIREMENTS.md).
